Global settings

Everything here is public. The switch below is what opens the Rewards page for visitors: while it is off, the page and the postback endpoint refuse every reward. No test points are ever created.

Providers

A provider is a survey wall, offerwall or rewarded-video network. Adding one is entirely configuration: paste the wall URL with a {uid} placeholder, set the postback parameter names your provider uses, choose how their postback is signed, and paste their shared secret. The secret is written to a node no browser can read back.

User lookup

Balances and transaction history are read from the server. Reversing a transaction takes the exact points back and records why — it never edits the original row.
