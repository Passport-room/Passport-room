Before you use any photo tool

Several authorities, including the three above, do not accept photos that have been digitally altered, which can include replacing the background. Read the official rules for your application first. Passport Room cannot guarantee that any authority will accept a photo.

Other sizes built into the tool (Schengen, India, Australia, China, Bangladesh) are listed in the size reference. Pages for those countries will be added only after each one is checked against an official source.
